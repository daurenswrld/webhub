# План развития и доработки веб-сайта WebHub

Этот документ содержит обновленный план по созданию премиального, интерактивного и технологичного интерфейса для WebHub, ориентированного на разработку сложных систем (сайты, маркетплейсы, ERP, CRM).

---

## [ТЕКУЩИЕ ЗАДАЧИ // РЕАЛИЗАЦИЯ]
- [x] Исключение биржи: Все ссылки и компоненты биржи полностью удалены.
- [x] Интерактивный супер-каталог услуг (Services Dashboard):
  - Создание панели управления услугами с 4 ключевыми направлениями:
    1. Сайты и Web Apps (с симулятором Lighthouse и скорости загрузки).
    2. Маркетплейсы (с симулятором транзакций и нагрузок).
    3. ERP-системы (с интерактивной мини-базой данных и финансовым графиком).
    4. CRM-системы (с интерактивной Kanban-доской сделок).
  - Интеграция калькулятора сметы и сроков прямо в каждую услугу.
  - Реализация анимаций переходов между вкладками услуг.
- [x] Инженерные стандарты и стек технологий (Ecosystem):
  - Создание интерактивной панели с переключателем категорий стека (Backend, Frontend, Databases, DevOps).
  - Описание и оформление инженерных принципов компании (Владение кодом, Автоматизация QA & CI/CD, Инфраструктура IaC).
- [x] Интерактивная консоль разработчика (Terminal Console):
  - Создание консольного компонента, имитирующего командную оболочку Linux (webhub@hq:~$ ).
  - Обработка интерактивных команд пользователя (help, about, services, standards, system, contact, clear, git status, sudo rm -rf).
  - Скроллинг истории ввода и автоматическое перенаправление на другие разделы страницы (например, скроллинг на форму заявки по команде "contact").
- [x] Интерактивный пульс разработки (Git Activity):
  - Создание сетки активности коммитов (GitHub Heatmap) с 350+ ячейками и интерактивным наведением курсора для отображения данных о коммитах.
  - Реализация лога Git Pushes в реальном времени, транслирующего события коммитов от команды разработчиков с автообновлением каждые 4.5 секунды.
  - Вывод глобальных метрик качества разработки (99.98% успешных CI/CD сборок, среднее число коммитов, отсутствие legacy багов).
- [x] Плавающий виджет быстрого действия и связи (Floating Contact):
  - Создание фиксированной кнопки в нижнем углу экрана с анимацией пульсирующего свечения.
  - При клике раскрывается меню с быстрыми ссылками (Telegram Direct, Телефонный звонок, Отправить форму, Запустить CLI-терминал с автоматическим фокусом).
  - Интеграция индикатора статуса Telegram-бота ("LEAD ROUTING BOT: ONLINE") и умной кнопки возврата наверх "Scroll to Top".
- [x] Виджет сетевого пинга узлов (Latency Monitor):
  - Разработка консольной панели мониторинга задержки серверов в реальном времени.
  - Динамическое обновление сетевого пинга до глобальных узлов (Алматы, Франкфурт, Сингапур, Нью-Йорк) с флуктуациями +/- 1мс каждые 2 секунды.
  - Интеграция виджета непосредственно в боковую панель контактов для улучшения технического имиджа студии.
- [x] Адаптивное бургер-меню (Mobile Navbar Overlay):
  - Интеграция кнопки-бургера с плавной CSS-анимацией трансформации в крестик при открытии.
  - Реализация полноэкранного размытого стеклянного (blur overlay) меню с крупными ссылками навигации для мобильных экранов.
  - Автоматическое закрытие оверлея при выборе любого из разделов навигации.

## [ДЕТАЛЬНОЕ ОПИСАНИЕ ИНТЕРАКТИВНЫХ ФИЧ КАТАЛОГА УСЛУГ]

### 1. [Сайты и Web Apps // Lighthouse Simulator]
- Суть: Клиент видит интерактивный экран, имитирующий аудит производительности сайта.
- Интерактив: Кнопка «Запустить тест оптимизации». При клике запускается быстрая анимация сканирования кода, выводящая показатели производительности (100% Performance, 100% SEO, 100% Accessibility).
- Стекинг: Показывает, за счет каких технологий (Vite, Next.js SSG, WebGL) достигается эта скорость.

### 2. [Маркетплейсы & E-commerce // Load & Transactions Simulator]
- Суть: Симуляция работы интернет-магазина в режиме реального времени.
- Интерактив: Кнопка «Сгенерировать пиковый трафик». Пользователь видит, как график запросов в секунду (RPS) подскакивает с 10 до 15 000, при этом статус сервера остается «Online (200 OK)» без задержек, благодаря архитектуре на Go/Redis.

### 3. [ERP системы // Enterprise Ledger & Analytics]
- Суть: Интерактивный мини-дашборд управления складом и финансами.
- Интерактив: Клиент может добавить тестовый «Расход» или «Приход» в таблицу, и график прибыли на лету пересчитывает баланс.

### 4. [CRM системы // Interactive Kanban Board]
- Суть: Интерактивная доска продаж.
- Интерактив: Kanban-доска с тремя колонками: «Лид», «Переговоры», «Сделка закрыта». Пользователь может перетаскивать карточки сделок мышкой или кликом, при этом срабатывает визуальный триггер «Отправка SMS клиенту» или «Выставление счета».
